# 后端集成测试计划

本轮只测试 Python 后端，不执行前端测试。以下项目是验收目标；只有实际运行通过的测试才计为完成。文档表格、链接检查不能证明应用功能可用。

测试使用独立的 MySQL 数据库，通过 FastAPI 的 HTTP 接口调用应用，并查询数据库核对最终状态。禁止将 SQLite 的测试结果作为 MySQL 外键、事务或并发行为的证明。数据库名必须以 `_test` 结尾，测试只能清理这个隔离数据库。

| 模块 | 实际验证内容 | 关键结果 |
|---|---|---|
| 数据库 | 运行迁移、查看引擎版本和业务表 | 确认为 MySQL，迁移能够创建业务关系。 |
| 邮箱登录 | 申请邮件挑战、从测试数据库解密验证码、验证和重复验证 | 申请不创建用户；成功验证创建一个用户；同一验证码只成功一次。HTTP 不泄漏验证码。 |
| 登录保护 | 错误次数、过期、重发旧码失效、不同用途隔离 | 已失效验证码不能创建登录；失败计数真实提交到数据库。 |
| 登录续期 | 使用续期凭证、重放旧凭证 | 成功轮换；旧凭证重用使所属登录撤销。 |
| 权限 | 普通用户请求编辑和审核接口、他人草稿 | 拒绝越权，不能只依靠前端隐藏按钮。 |
| Notes | 纯文字发布、图片顺序、拒绝专业正文和视频 | 公开内容独立保存；无图合法；不会接受 Editor 正文模型。 |
| Editor | 地点文章、活动文章、互斥主要对象、正文块、可选封面 | 地点文章无需活动；活动场地待定可发布；专业媒体顺序保留。 |
| 审核顺序 | 已公开版本后再提交两次，先批准较旧提交 | 旧审核不覆盖较新提交；草稿修改不泄漏到公开正文。 |
| 并发 | 同版本保存、重复提交请求、同次审核同时批准 | 使用独立 MySQL 连接产生真实竞争；最多一份提交或一次状态变更。 |
| 城市区域 | 区属于另一城市、主要对象城市不一致 | API 拒绝，数据库实际关联也保护城市与区。 |
| 媒体授权 | 作者读取、他人读取、编辑人员读取私人图片、审核上下文读取 | 私有媒体不向无关用户泄漏；审核只获得当前提交涉及文件。 |
| 后台任务 | 两个进程领取、领取期限过期后重领、旧领取者写回 | 一份有效领取；旧领取者不能覆盖新进程结果。 |

测试不会发送真实邮件。验证码发送内容通过隔离测试数据库读取，或使用本地邮件接收服务。媒体存储外部调用可使用受控替身；这种测试只证明业务授权与状态转换，不能宣称已验证真实云服务或视频设备兼容性。
