# 开发上下文与分工

本轮开始将设计落实为代码。范围以 `docs/architecture` 的四份方案和下列已确认修正为准。

- 首发上海，客户端 React Native + TypeScript + Expo；编辑后台 React 网页应用，不做 Electron。
- Python + FastAPI，MySQL 8.4。后端按职责分模块，暂不拆微服务；MySQL 任务表配独立 worker，暂不引入外部消息队列。
- 只做邮箱验证码注册和登录，不保留手机注册、密码登录或个性化开关。
- Discover 两个 Tab 为“活动”和 Notes，底部为 Discover、搜索、个人；搜索保留入口。第一版没有 Agent 或 AI 编辑工作流。
- Editor 文章独立建模，由编辑选择地点或活动重心；专业文档支持指定位置图片、视频、链接、图注和排版。文章保存城市与区，已发布地区随公开版本切换。
- Notes 独立建模，为可选标题、普通文字及最多九张有序图片。至少正文或图片之一非空，不用专业富文本编辑器。
- 封面、地点照片及文章图片全部可选，纯文字内容正常展示。
- 图片视频放对象存储，数据库只保存资料和引用。草稿与待审资料默认私有。
- 卡其色为主、深绿色为辅；参考 Mars 城市生活产品方向，尚无可核实的指定版本截图，不声称逐像素复刻。
- 用户要求暂不做前端测试。本轮只对后端安排自动化测试；前端构建和依赖安装不等于设备体验验证。

## 当前分工

| 角色 | 负责范围 |
|---|---|
| 根 agent | 手机端、共享请求与配色、本地运行配置、接口整合和最终完成度审查 |
| coding_agent | 后端数据模型、迁移、接口、后台任务和权限 |
| editor_coding_agent | 网页编辑后台、专业编辑器和专业文档类型 |
| test_agent | 独立 MySQL 后端测试、并发与权限验证、记录缺口 |

各 agent 只编辑自己负责的目录，发现接口不一致时先沟通，不通过削减需求让测试通过。运行结果和剩余工作记录在本目录；设计文档不是完成证明。

## 本轮落地状态

上述三名子 agent 已分别交付后端、后台编辑器和测试代码；后续因用量限制停止，根 agent 接手接口整合、并发修复、手机端、运行配置与最终检查。没有因子 agent 停止而跳过必要后端验证。具体运行结果以 [验证记录](verification.md) 为准。
