# Discover 分页改版验证（2026-09-29）

## 改动范围

- Discover 删除顶部 `THE CITY IS YOURS` 与 `日常之外，城市之中。` 两行标语，收紧标题间距。
- “活动”（编辑文章）和 Notes（用户笔记）放进原生横向分页区域；点击标签滚动到对应页，滑动结束更新选中标签。
- 两个纵向列表分别挂载，分别保存滚动位置、查询结果、刷新与分页状态；相邻页提前加载，只有当前页定时刷新和触底加载。
- 地区筛选条位于横向分页区域外，保留编辑文章的筛选条件；用户笔记请求不带地区条件。

## 已确认

- `pnpm --filter @marcus/mobile typecheck` 通过。
- `pnpm --filter @marcus/mobile exec expo export --platform ios --output-dir /tmp/marcus-discover-ios-export` 成功生成 iOS JavaScript bundle；这不是原生编译或手势测试。
- `git diff --check` 通过。
- iPhone 18 Pro / iOS 27.0 模拟器加载了修改后的页面：顶部标语消失，品牌、城市和板块标签保留。
- 实际点击 Notes 后，Notes 选中，出现本地数据库的图片笔记与文字笔记；点击活动后，活动选中且出现两篇编辑文章。
- 点击宝山区后显示文章空态，筛选操作没有跳到 Notes。
