## 环境与方法

- Vite `http://localhost:5173`，FastAPI 8000，MySQL、Redis、worker、Moto S3 9000、Mailpit 8025/1025 均实际运行。

## 本次发现并独立回归的修复

1. `Moderation.tsx` 列表、详情初始查询键均为 `[path, undefined]`，导致未选择内容就显示“无标题笔记”和批准按钮。coding agent 将 list/detail 查询键分开，并要求 selected 存在。回归了初始页、选择详情、批准后清空、Notes 切换和举报空态。
2. 富文本调用 `setEditable` 默认触发 update，导致正常加载、保存或重进编辑器就显示“有未保存修改”。coding agent 禁用该调用的内容更新通知。回归了 reload、预览往返均已保存；真实媒体/文字改动变未保存；保存后和再次 reload 已保存。
3. 文章请求 404 时仍显示“正在加载文章…”。coding agent 让错误时不显示加载文案。无效 ID 与正常文章均重新验证。
