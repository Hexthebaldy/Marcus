# Marcus 城市编辑室

在浏览器中运行的 React + TypeScript 编辑后台。包含邮箱验证码登录、地点与活动资料、场次、标签、专业文章编辑与预览、固定提交审核、举报处理、下架恢复及人员权限。

从仓库根目录安装依赖后运行：

```sh
pnpm editor
```

复制本目录 `.env.example` 为 `.env.local` 可调整后端地址。默认前端为 `http://localhost:5173`，后端为 `http://localhost:8000/v1`。后端允许来源需与前端地址一致；浏览器登录续期使用受保护 Cookie，短期访问凭证只保存在内存中。网页刷新后会用 Cookie 恢复会话。

先通过后端 seed / 管理命令为已验证邮箱授予 `editor`、`moderator` 或 `admin`。普通账户可以登录，但看不到管理功能。编辑人员可创建资料与文章；审核员可查看固定提交、批准或拒绝、处理举报。后端独立验证这些权限。

文章正文使用 `@marcus/editorial-editor` 的 Tiptap 编辑组件；可在当前位置插入图片、视频或图片组，编辑图注和来源署名，选择宽度。`@marcus/editorial-schema` 定义与手机共用的正文格式。预览可切换手机与桌面宽度；桌面双列图片在手机预览中按原顺序排列。

编辑采用显式保存。提交审核会先保存当前草稿，再提交对应保存版本。版本冲突保留当前文字，由编辑决定复制内容后重新加载。提交失败后的重试复用请求编号。封面始终可选。

`pnpm --filter @marcus/editor build` 负责 TypeScript 编译与生产打包。按用户要求，当前未运行前端单元测试或浏览器测试。首次真实设备与人工验收应在上线前补齐。

当前 `/terms` 与 `/privacy` 是开发环境使用说明，正式运营需要填写运营主体、联系方式和完整保留政策。
